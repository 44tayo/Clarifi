# Clarifi product brief

**One-liner:** Clarifi is the AI notepad for back-to-back meetings — for everyone in Europe (and anyone Granola locks out).

## Job to be done

> I leave every call with notes I trust, without a bot joining the meeting.

## Positioning

| | Clarifi | Granola | Jamie |
|---|---|---|---|
| Promise | Personal AI notepad for every meeting | Same, US/work-email skewed | Privacy-first for high-stakes teams |
| Who | Individuals, freelancers, anyone with meetings | Founders / knowledge workers | Teams that need shared workspaces |
| Capture | On-device, no bot | On-device, no bot | On-device, no bot |
| During call | Light notes + floating widget + scratchpad | Light notes | Scratchpad + floating widget |
| After call | Structured summary, decisions, actions, transcript | Same + recipes | Same + templates + Ask AI |
| Europe | Personal email OK; honest EU trust path | Work-email friction; US product | Already owns EU privacy niche |

**Lead with:** jot a few words → Clarifi listens → hang up → clean notes. Works with Zoom / Meet / Teams / in-person. Sign up with any email.

**Do not lead with:** “most private in Europe” (Jamie owns that) or “invisible interview copilot” (old Cluely).

## First-class product pillars

1. **Notepad loop** — user notes + transcript → polished summary
2. **Floating during-meeting widget** — always-on-top pill (timer / stop / focus app)
3. **Scratchpad** — private in-call notes, distinct from summary / transcript tabs

## Competitive rule

Copy Granola’s *job* (personal AI notepad for meetings), not Jamie’s *team privacy* brand. Copy Jamie’s *widget / scratchpad* UX patterns only where they serve the notepad.

## MVP success metric

A new user can: first launch → grant permissions → record a call → see a summary within ~60 seconds after stopping — without developer help.

## First-run auth

Onboarding Sign up / Login opens the website (Google / Microsoft / Apple / email) and pairs via `clarifi://` deep link — same account as clarifiapp.com.

## Explicit non-goals for v1

Team workspaces, People directory, referral program, calendar auto-start, Ask AI across all meetings, template library, iOS app.
